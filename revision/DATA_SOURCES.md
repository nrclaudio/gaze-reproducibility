# Data and implementation provenance

- CAMP source: Benedetti et al., *A Multimodal Atlas of Tumor Metabolism Reveals the Architecture of Gene–Metabolite Covariation*, Nature Communications (2023), doi:10.1038/s41467-023-40217-2. Versioned source deposit: https://doi.org/10.5281/zenodo.7874228 (CC BY 4.0). The deposited metadata and upstream file checksums are in `sources/camp_zenodo_record.json`.
- The processed MuData retains 867 paired samples after removing 121 samples with negative processed metabolite values from 988 pairs. It contains the 1,152 annotated source features and the 2,184-gene RNA input used here. It is not a panel consisting exclusively of cell lines. Feature mapping, observation and eligible evaluation-target counts are distinct; see the target annotation notes and mapping tables.
- `external/artifacts/preparation_summary.json` records the processed input hashes, exclusions and preparation details. Source-study preprocessing is retained. The source-workbook metabolite values are relative intensities, not calibrated concentrations. MuData, identifiers and split manifests are supplied for direct reproduction, rather than reconstructed by requerying an API.
- Graph: the frozen merged graph and gene mapping used by the ALICE models are supplied with checksums. The graph derives from the MetabolicAtlas reconstruction with enzyme embeddings and ChemBERTa descriptors. Current API downloads can change topology or ordering; they must not be substituted into a saved checkpoint. Graph-building source remains under `scripts/graph_generation`.
- UnitedMet: original implementation is attributed to the upstream repository and commit in `experiments/unitedmet49/upstream/commit.json`; its MIT license is retained. The two required upstream modules are copied unchanged. The wrapper implements the globally masked target experiment specified by `protocol.json`.
- MEBOCOST and scCellFie: fixed task/gene associations, saved activities, paired measurement masks and figure tables are provided in `manuscript_data`. See the manuscript references for the original tools. The bulk-TPM scCellFie adaptation preserves synthesis, degradation, salvage and conversion associations. It does not equate a task activity score with a direct metabolite abundance prediction.

Released external checkpoints are paired with their original configurations, graph, mapping and input hash. The 170 GAZE fit outputs and 49 UnitedMet posteriors are included. Per-target GAZE LOMO checkpoints are not included: their recorded hashes, predictions, configurations, epoch histories and complete retraining code are supplied. The older 867-sample deployment weights in the GAZE repository are a separate model and are not used for the external validation reported here.

Frozen experiment records preserve original execution metadata, including the original local/HPC paths. Execution helpers build paths from the supplied bundle directory; those original paths are provenance, not runtime requirements.
